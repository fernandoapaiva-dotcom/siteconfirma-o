# Diretrizes de Autonomia e Execução Automática

- **Execução 100% Autônoma:** Execute todas as instruções de ponta a ponta sem solicitar confirmações intermediárias ou perguntar sobre procedimentos triviais (edição de código, criação de arquivos, testes, commits, deploys, reinício de containers, etc.).
- **Proatividade Total:** Identifique problemas, diagnostique, implemente a solução, teste, publique/faça deploy e valide o resultado final de forma independente.
- **Sem Paradas Desnecessárias:** Nunca pare no meio de uma tarefa para pedir permissão para rodar comandos ou aplicar correções necessárias; conclua todo o fluxo solicitado pelo usuário.
- **Comunicação Direta:** Após concluir tudo com sucesso, responda de forma concisa e objetiva com o resumo do que foi executado e validado.
